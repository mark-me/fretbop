# Only permissively licensed dependencies

Dependencies must use a permissive license (MIT, BSD, ISC, 0BSD, Apache-2.0); copyleft (GPL, AGPL) is excluded, including transitively, and CI enforces this with pip-licenses and license-checker.

## Considered Options

- **Essentia.js** and **pitchfinder** — rejected: AGPL-3.0 and GPL-3.0 respectively, despite strong audio-analysis features.
