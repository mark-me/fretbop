# The project is named Fretbop

Fretbop (fret + bebop) covers every fretted instrument, so the name still fits when guitar and bass are added. No clashes were found on PyPI, npm or GitHub; a trademark check (TMview, USPTO) is still to be done.

## Considered Options

- **Uketude, Ukebop** — rejected: tied to the ukulele.
- **Vamplet** — rejected: too close to the Vamp audio-analysis plugin API and the Vampr musician app.
- **Guidetone, Comptone, Changewise** — rejected: already in use on GitHub.
